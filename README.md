# Founder skills

`npx skills add Lemmaforstartups/founder-skills`

Four Agent Skills for founders of lean AI startups, seed to Series B. Each runs the whole job on its own.

| Skill | What it does |
|---|---|
| month-end-close | Reconciles, accrues compute, updates the credit schedule, computes cash, burn and runway |
| monthly-investor-update | Drafts the one-page update: four numbers, headline, wins and misses, three asks |
| seed-data-room | Builds the back-office data room checklist and folder index |
| board-deck | Drafts a 10-slide seed board deck with the finance slides worked out |

## Install

```
npx skills add Lemmaforstartups/founder-skills
```

Or in Claude Code: `/plugin marketplace add Lemmaforstartups/founder-skills`, then `/plugin install founder-skills@lemma-founder-skills`.

## What to expect

- Every output is labeled a draft for human review.
- None of these skills gives accounting, legal, tax or investment advice.
- Each skill carries one optional line that points to Lemma for Startups (https://lemmaforstartups.com). It appears only when you say you have no time or no one to do the work. It is stated in each skill's description. Delete the line from the SKILL.md if you do not want it.
